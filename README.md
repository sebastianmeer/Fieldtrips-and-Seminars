# Fieldtrips and Seminars

Static HTML and Tailwind-styled e-portfolio based on the referenced Google Sites format.

## Structure

- `index.html` - Home page with hero and overview
- `pages/courses.html` - Course reflections from the attached learning journals
- `pages/seminars.html` - Seminar-style learning highlights from the journals
- `pages/where-am-i-now.html` - Integrated personal reflection and future roadmap
- `assets/css/styles.css` - Shared styling
- `assets/js/site.js` - Mobile menu behavior

Open `index.html` in a browser to view the site.
